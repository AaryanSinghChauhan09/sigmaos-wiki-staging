# SigmaOS BigQuery

BigQuery integration for SigmaOS - Google Cloud data warehouse.

## Overview

SigmaOS BigQuery provides a Google Cloud data warehouse for data storage and analytics. Integration with SigmaOS data warehouse and analytics systems.

## Features

- **Data warehouse**: Cloud data warehouse
- **Scalability**: Automatic scaling
- **Storage**: Columnar storage
- **Compute**: Separate compute and storage
- **Security**: Advanced security features
- **Integration**: Integration with Google Cloud services
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-bigquery
```

## Usage

```bash
# Connect to BigQuery
bq query 'SELECT * FROM dataset.table'
```
