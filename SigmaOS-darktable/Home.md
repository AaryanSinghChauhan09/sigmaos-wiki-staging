# SigmaOS Darktable

Darktable integration for SigmaOS - photo workflow and raw developer.

## Overview

SigmaOS Darktable provides a photo workflow and raw developer for professional photographers. Integration with SigmaOS creative and photography systems.

## Features

- **Raw development**: Develop raw photos
- **Photo workflow**: Complete photo workflow
- **Color management**: Color management
- **Non-destructive**: Non-destructive editing
- **Modules**: Modular processing pipeline
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-darktable
```

## Configuration

Darktable is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/darktable/`.

## Usage

```bash
# Start Darktable
sigmaos-darktable
```
