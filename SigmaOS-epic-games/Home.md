# SigmaOS Epic Games

Epic Games integration for SigmaOS - Epic Games Store launcher.

## Overview

SigmaOS Epic Games provides an Epic Games Store launcher for Linux. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Epic Games Store**: Access Epic Games Store
- **Game library**: Manage game library
- **Cloud saves**: Cloud save synchronization
- **Proton**: Proton compatibility layer
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for performance
- **Community**: Community features
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-epic-games
```

## Configuration

Epic Games is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/epic-games/`.

## Usage

```bash
# Start Epic Games
sigmaos-epic-games
```
