# SigmaOS Draw.io

draw.io integration for SigmaOS - diagramming tool.

## Overview

SigmaOS Draw.io provides a diagramming tool for creating flowcharts, diagrams, and visualizations. Integration with SigmaOS productivity and design systems.

## Features

- **Diagramming**: Create various types of diagrams
- **Flowcharts**: Flowchart creation
- **UML**: UML diagram support
- **Network diagrams**: Network diagram support
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Collaboration**: Real-time collaboration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-drawio
```

## Configuration

Draw.io is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/drawio/`.

## Usage

```bash
# Start Draw.io
sigmaos-drawio
```
