# SigmaOS VSCode

Visual Studio Code integration for SigmaOS - code editor with SigmaOS theme integration.

## Overview

SigmaOS VSCode provides a powerful code editor with rich extensions and SigmaOS theme integration. Built on Visual Studio Code with SigmaOS-specific configurations.

## Features

- **Code editing**: Syntax highlighting, IntelliSense, and code completion
- **Extensions**: Rich extension ecosystem
- **Debugging**: Built-in debugger for multiple languages
- **Git integration**: Source control management
- **Terminal**: Integrated terminal
- **Themes**: SigmaOS theme integration
- **Remote development**: SSH, containers, and WSL support
- **Settings sync**: Settings synchronization across devices

## Installation

```bash
sudo pacman -S sigmaos-vscode
```

## Configuration

VSCode is configured to use the SigmaOS theme system. Settings are stored in `~/.config/Code/User/settings.json`.

## Usage

```bash
# Start VSCode
sigmaos-vscode

# Open a file
sigmaos-vscode file.txt

# Open a directory
sigmaos-vscode .
```
