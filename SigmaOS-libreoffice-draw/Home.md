# SigmaOS LibreOffice Draw

LibreOffice Draw integration for SigmaOS - vector graphics editor.

## Overview

SigmaOS LibreOffice Draw provides a vector graphics editor for creating diagrams and illustrations. Integration with SigmaOS office and design systems.

## Features

- **Vector graphics**: Create vector graphics
- **Diagrams**: Create flowcharts and diagrams
- **Drawing tools**: Various drawing tools
- **Text tools**: Text editing tools
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-draw
```

## Configuration

LibreOffice Draw is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Draw
sigmaos-libreoffice-draw
```
