# SigmaOS Craft

Creative suite for SigmaOS - 3D, animation, art, CAD, and design tools.

## Overview

SigmaOS Craft provides a comprehensive creative suite for 3D modeling, animation, digital art, CAD, and design work on SigmaOS.

## Features

- **3D modeling**: 3D modeling and rendering tools
- **Animation**: Animation and motion graphics
- **Digital art**: Digital painting and illustration
- **CAD**: Computer-aided design tools
- **Design libraries**: Shared libraries for creative tools
- **Deck**: Creative project management
- **Effect**: Visual effects and compositing
- **File format support**: Import/export for common creative formats

## Creative Components

- 3D: 3D modeling tools
- Ani: Animation tools
- Art: Digital art tools
- CAD: Computer-aided design
- CraftLibs: Shared creative libraries
- Deck: Project management
- Design: Design tools
- Effect: Visual effects
- Fig: Vector graphics
- Film: Video editing
- Font: Font management
- Grid: Layout tools
- Light: Lighting tools
- PDF: PDF tools
- Photo: Photo editing
- Print: Print preparation
- Sound: Audio editing
- Vector: Vector graphics
- Voice: Voice editing
- Word: Document creation
