# Sigma

> SigmaOS - A modular Linux distribution focused on security, privacy, and desktop experience

## Status

- **Component**: Sigma
- **State**: Implemented — source code present
- **Source**: https://github.com/AaryanSinghChauhan09/Sigma

## Overview

SigmaOS is an **Arch-based Linux distribution** built on the stock Linux kernel and official Arch packages, with an Omarchy-inspired pre-configured Hyprland desktop. It is not a custom-kernel project.
