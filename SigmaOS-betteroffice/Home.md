# SigmaOS BetterOffice

Office suite for SigmaOS - diagrams, documents, spreadsheets, and slides.

## Overview

SigmaOS BetterOffice provides a comprehensive office suite for creating diagrams, documents, spreadsheets, and presentations on SigmaOS.

## Features

- **Diagrams**: Diagram creation and editing tools
- **Documents**: Word processing and document creation
- **Spreadsheets**: Spreadsheet applications with calculation support
- **Slides**: Presentation software
- **Collaboration**: Real-time collaboration features
- **Format compatibility**: Support for common office file formats

## Components

- Diagrams: Diagram creation tools
- Documents: Word processing
- Spreadsheets: Spreadsheet applications
- Slides: Presentation software
