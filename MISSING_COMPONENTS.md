# Missing Components

Components identified as missing based on comparison with Arch Linux and Omarchy Linux.

## Browsers

Existing:
- SigmaOS-browser
- SigmaOS-chromium

Missing (from requirements):
- SigmaOS-firefox
- SigmaOS-brave
- SigmaOS-librewolf
- SigmaOS-waterfox
- SigmaOS-zen

## Office Suites

Existing:
- SigmaOS-betteroffice
- SigmaOS-genoffice

Missing (from requirements):
- SigmaOS-libreoffice
- SigmaOS-onlyoffice

## Development Tools

Existing:
- Various dev tools

Missing (from requirements):
- Additional IDE support
- More language runtimes

## Status

Due to GitHub repository creation rate limits, these components will be created when the limit resets. In the meantime, the centralized Wiki staging repository serves as the complete catalog.

## Priority

1. High priority: Browsers (Firefox, Brave)
2. Medium priority: Office suites (LibreOffice)
3. Low priority: Additional dev tools
