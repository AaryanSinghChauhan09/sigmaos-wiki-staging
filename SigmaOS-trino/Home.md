# SigmaOS Trino

Trino distributed SQL query engine integration for SigmaOS with enhanced configuration and cluster support.

## Overview

SigmaOS Trino provides Trino (formerly PrestoSQL) distributed SQL query engine with SigmaOS integration, optimized configuration, and federated query support across multiple data sources.

## Features

- Trino distributed SQL engine
- Federated query across data sources
- ANSI SQL support
- Multiple connector support
- SigmaOS integration
- Local and cluster modes

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install trino
```

## Components

Trino includes:

- **Trino Server**: Distributed query engine
- **Trino CLI**: Command-line interface
- **Connectors**: PostgreSQL, MySQL, Hive, Iceberg, Delta Lake
- **Catalog**: Multi-catalog support

## Configuration

Trino is pre-configured with:
- SigmaOS memory settings
- Optimized local mode
- Common connector configurations
- Catalog manager
