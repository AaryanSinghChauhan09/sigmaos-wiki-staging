# SigmaOS-trino

Trino/Presto distributed SQL query federation client in Rust for SigmaOS.

## Overview

`SigmaOS-trino` provides a Rust client abstraction for Trino/Presto query federation, including protocol header construction, catalog registry validation, and query state tracking.
