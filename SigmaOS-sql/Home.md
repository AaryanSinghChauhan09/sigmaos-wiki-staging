# SigmaOS SQL

SQL integration for SigmaOS - Structured Query Language tools.

## Overview

SigmaOS SQL provides Structured Query Language tools and interfaces. Integration with SigmaOS database and data analysis systems.

## Features

- **SQL clients**: Multiple SQL clients
- **Query tools**: Query builders and tools
- **Database support**: Support for multiple databases
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Examples**: SQL examples
- **Performance**: Optimized for performance
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-sql
```

## Usage

```sql
-- SQL query
SELECT * FROM users WHERE age > 18;
```
