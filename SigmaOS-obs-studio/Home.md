# SigmaOS OBS Studio

OBS Studio integration for SigmaOS - video recording and live streaming.

## Overview

SigmaOS OBS Studio provides video recording and live streaming software. Integration with SigmaOS media and streaming systems.

## Features

- **Video recording**: Record video
- **Live streaming**: Stream to various platforms
- **Scene composition**: Compose scenes with sources
- **Audio mixing**: Audio mixing and effects
- **Transitions**: Scene transitions
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-obs-studio
```

## Configuration

OBS Studio is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/obs-studio/`.

## Usage

```bash
# Start OBS Studio
sigmaos-obs-studio
```
