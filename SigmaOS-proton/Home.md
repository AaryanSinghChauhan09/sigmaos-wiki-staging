# SigmaOS Proton

Proton integration for SigmaOS - Wine-based compatibility layer for gaming.

## Overview

SigmaOS Proton provides a Wine-based compatibility layer for running Windows games on Linux. Integration with SigmaOS performance optimizations and theme system.

## Features

- **Windows games**: Run Windows games
- **Wine/Proton**: Based on Wine and Proton
- **Anti-cheat**: Support for anti-cheat systems
- **Performance**: Optimized for gaming performance
- **Themes**: SigmaOS theme integration
- **Dependencies**: Automatic dependency installation
- **Launchers**: Support for Steam and other launchers
- **Compatibility**: Wide game compatibility

## Installation

```bash
sudo pacman -S sigmaos-proton
```

## Configuration

Proton is configured to use SigmaOS performance settings. Proton versions are stored in `~/.steam/steam/compatibilitytools.d/`.

## Usage

```bash
# Use Proton with Steam
# In Steam settings, select Proton as compatibility tool

# Run Proton directly
proton run game.exe
```
