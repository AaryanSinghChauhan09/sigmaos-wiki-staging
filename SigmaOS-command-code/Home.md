# SigmaOS Command Code

Command Code integration for SigmaOS - command-line code editor.

## Overview

SigmaOS Command Code provides a command-line code editor for quick code editing. Integration with SigmaOS development tools.

## Features

- **CLI editor**: Command-line code editor
- **Syntax highlighting**: Syntax highlighting
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **File management**: File management
- **Search**: Search and replace
- **Documentation**: Comprehensive documentation
- **Performance**: Optimized for performance

## Installation

```bash
sudo pacman -S sigmaos-command-code
```

## Configuration

Command Code is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/command-code/`.

## Usage

```bash
# Start Command Code
sigmaos-command-code

# Edit a file
command-code file.py
```
