# SigmaOS Local Send

Local Send integration for SigmaOS - local file sharing.

## Overview

SigmaOS Local Send provides local file sharing between devices on the same network. Integration with SigmaOS file sharing and communication systems.

## Features

- **Local sharing**: Share files locally
- **No internet**: No internet required
- **Cross-platform**: Works across platforms
- **File transfer**: File transfer between devices
- **Security**: Encrypted file transfer
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-local-send
```

## Configuration

Local Send is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/local-send/`.

## Usage

```bash
# Start Local Send
sigmaos-local-send

# Share a file
local-send share file.txt

# Receive files
local-send receive
```
