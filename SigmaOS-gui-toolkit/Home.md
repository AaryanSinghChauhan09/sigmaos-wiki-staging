# SigmaOS GUI Toolkit

GUI toolkit collection for SigmaOS - collection of GUI frameworks and toolkits.

## Overview

SigmaOS GUI Toolkit provides a collection of GUI frameworks and toolkits for building desktop applications. Includes bindings for multiple frameworks.

## Features

- **Framework bindings**: Qt, GTK, Electron, Tauri, Wails, and more
- **Cross-platform**: Works across platforms
- **Theme integration**: SigmaOS theme support
- **Component library**: Reusable UI components
- **Documentation**: Comprehensive documentation
- **Examples**: Example applications
- **Performance**: Optimized for performance
- **Accessibility**: Accessibility support

## Frameworks Included

- **Qt**: Qt Quick and Qt Widgets
- **GTK**: GTK3 and GTK4 with libadwaita
- **Electron**: Electron.js
- **Tauri**: Tauri framework
- **Wails**: Wails framework
- **Flutter**: Flutter framework
- **React Native**: React Native Desktop
- **Python**: PyQt, PySide, tkinter
- **Rust**: Iced, Slint, egui

## Installation

```bash
sudo pacman -S sigmaos-gui-toolkit
```

## Configuration

GUI Toolkit is configured to use the SigmaOS theme system. Frameworks are managed via package manager.

## Usage

```bash
# Install GUI toolkit
sudo pacman -S sigmaos-gui-toolkit

# List available frameworks
gui-toolkit list

# Install a framework
gui-toolkit install qt
```
