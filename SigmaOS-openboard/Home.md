# SigmaOS OpenBoard

OpenBoard integration for SigmaOS - interactive whiteboard.

## Overview

SigmaOS OpenBoard provides an interactive whiteboard for education and presentations. Integration with SigmaOS education and presentation systems.

## Features

- **Interactive whiteboard**: Interactive whiteboard
- **Drawing tools**: Various drawing tools
- **Presentation mode**: Presentation mode
- **Collaboration**: Real-time collaboration
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Education**: Education-focused features
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-openboard
```

## Configuration

OpenBoard is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/openboard/`.

## Usage

```bash
# Start OpenBoard
sigmaos-openboard
```
