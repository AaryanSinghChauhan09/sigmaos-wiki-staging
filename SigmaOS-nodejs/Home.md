# SigmaOS Node.js

Node.js integration for SigmaOS - JavaScript runtime.

## Overview

SigmaOS Node.js provides the Node.js JavaScript runtime with SigmaOS-specific configurations and package management.

## Features

- **JavaScript runtime**: Latest Node.js version
- **npm**: Node package manager
- **SigmaOS bindings**: SigmaOS-specific Node.js bindings
- **Development tools**: Development tools and libraries
- **TypeScript support**: TypeScript compiler integration
- **Themes**: SigmaOS theme integration for Node.js tools

## Installation

```bash
sudo pacman -S sigmaos-nodejs
```

## Configuration

Node.js is configured to use SigmaOS package management. Packages are installed in `~/.local/share/npm/`.

## Usage

```bash
# Run Node.js
node

# Run a file
node script.js

# Install packages
npm install package-name
```
