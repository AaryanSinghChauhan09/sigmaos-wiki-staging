# SigmaOS GOG

GOG integration for SigmaOS - GOG.com game launcher.

## Overview

SigmaOS GOG provides a GOG.com game launcher for Linux. Integration with SigmaOS gaming and entertainment systems.

## Features

- **GOG.com**: Access GOG.com games
- **Game library**: Manage game library
- **Cloud saves**: Cloud save synchronization
- **DRM-free**: DRM-free games
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for performance
- **Community**: Community features
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-gog
```

## Configuration

GOG is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/gog/`.

## Usage

```bash
# Start GOG
sigmaos-gog
```
