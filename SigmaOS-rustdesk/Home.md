# SigmaOS RustDesk

RustDesk integration for SigmaOS - remote desktop software.

## Overview

SigmaOS RustDesk provides a remote desktop solution for accessing and controlling remote machines. Peer-to-peer connections with SigmaOS integration.

## Features

- **Remote desktop**: Access remote machines
- **Peer-to-peer**: Direct device-to-device connection
- **File transfer**: Transfer files between machines
- **Screen sharing**: Share your screen
- **Chat**: Built-in chat
- **Recording**: Record remote sessions
- **Portable**: Portable executable available
- **Themes**: SigmaOS theme integration
- **Encryption**: End-to-end encryption
- **Self-hosted**: Option to use own relay server

## Installation

```bash
sudo pacman -S sigmaos-rustdesk
```

## Configuration

RustDesk is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/RustDesk/`.

## Usage

```bash
# Start RustDesk
sigmaos-rustdesk

# Start RustDesk in headless mode
sigmaos-rustdesk --port 21117
```
