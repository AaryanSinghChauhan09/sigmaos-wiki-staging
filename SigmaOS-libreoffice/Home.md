# SigmaOS LibreOffice

LibreOffice office suite configured for SigmaOS with enhanced integration and theming.

## Overview

SigmaOS LibreOffice provides the complete LibreOffice office suite with SigmaOS theming, enhanced performance, and desktop integration.

## Features

- Writer (word processor)
- Calc (spreadsheets)
- Impress (presentations)
- Draw (vector graphics)
- Base (database)
- Math (formula editor)
- SigmaOS theme integration
- Enhanced performance

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install libreoffice
```

## Components

The LibreOffice suite includes:

- **Writer**: Word processing with SigmaOS templates
- **Calc**: Spreadsheets with enhanced formulas
- **Impress**: Presentations with SigmaOS themes
- **Draw**: Vector graphics editor
- **Base**: Database management
- **Math**: Formula editor

## Configuration

LibreOffice is pre-configured with:
- SigmaOS theme support
- Custom templates
- Enhanced performance settings
- SigmaOS file picker integration
