# SigmaOS Steam

Steam integration for SigmaOS - digital distribution platform.

## Overview

SigmaOS Steam provides a digital distribution platform for games and software. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Game library**: Manage game library
- **Steam Store**: Browse and purchase games
- **Cloud saves**: Cloud save synchronization
- **Steam Workshop**: Mod support
- **Community**: Community features
- **Themes**: SigmaOS theme integration
- **Proton**: Proton compatibility layer
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-steam
```

## Configuration

Steam is configured to use the SigmaOS theme system. Configuration is stored in `~/.steam/`.

## Usage

```bash
# Start Steam
sigmaos-steam
```
