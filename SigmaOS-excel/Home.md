# SigmaOS Excel

Excel integration for SigmaOS - spreadsheet application.

## Overview

SigmaOS Excel provides a spreadsheet application for data analysis and visualization. Integration with SigmaOS office and data analysis systems.

## Features

- **Spreadsheet**: Spreadsheet application
- **Formulas**: Formula support
- **Charts**: Chart creation
- **Pivot tables**: Pivot table support
- **Data analysis**: Data analysis tools
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-excel
```

## Usage

```bash
# Start Excel
sigmaos-excel
```
