# SigmaOS Cryptomator

Cryptomator integration for SigmaOS - client-side encryption for cloud storage.

## Overview

SigmaOS Cryptomator provides client-side encryption for cloud storage. Integration with SigmaOS security and cloud storage systems.

## Features

- **Client-side encryption**: Client-side encryption
- **Cloud storage**: Works with various cloud storage providers
- **Vaults**: Create encrypted vaults
- **Transparent encryption**: Transparent file encryption
- **Mobile support**: Mobile app support
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-cryptomator
```

## Configuration

Cryptomator is configured to use SigmaOS security policies. Vaults are stored in `~/Cryptomator/`.

## Usage

```bash
# Start Cryptomator
sigmaos-cryptomator

# Create a vault
cryptomator create-vault

# Unlock a vault
cryptomator unlock-vault
```
