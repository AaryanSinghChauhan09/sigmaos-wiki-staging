# SigmaOS Playnite

Playnite integration for SigmaOS - game library manager.

## Overview

SigmaOS Playnite provides a game library manager for Windows games on Linux. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Game library**: Manage game library
- **Emulator support**: Emulator integration
- **Metadata**: Game metadata and artwork
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for performance
- **Community**: Community features
- **Customization**: Customizable interface
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-playnite
```

## Configuration

Playnite is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/playnite/`.

## Usage

```bash
# Start Playnite
sigmaos-playnite
```
