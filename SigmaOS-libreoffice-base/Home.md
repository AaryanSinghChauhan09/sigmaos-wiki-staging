# SigmaOS LibreOffice Base

LibreOffice Base integration for SigmaOS - database management.

## Overview

SigmaOS LibreOffice Base provides database management software for creating and managing databases. Integration with SigmaOS office and database systems.

## Features

- **Database management**: Create and manage databases
- **Tables**: Table creation and management
- **Queries**: Query builder
- **Forms**: Form creation
- **Reports**: Report generation
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-base
```

## Configuration

LibreOffice Base is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Base
sigmaos-libreoffice-base
```
