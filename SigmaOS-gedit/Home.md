# SigmaOS Gedit

Gedit integration for SigmaOS - GNOME text editor.

## Overview

SigmaOS Gedit provides a simple, clean text editor with SigmaOS theme integration.

## Features

- **Simple interface**: Clean, easy-to-use interface
- **Syntax highlighting**: Support for many languages
- **Spell checking**: Built-in spell checker
- **Plugins**: Extensible plugin system
- **Themes**: SigmaOS theme integration
- **File browser**: Built-in file browser
- **Search and replace**: Advanced search and replace
- **Multi-tab editing**: Edit multiple files in tabs

## Installation

```bash
sudo pacman -S sigmaos-gedit
```

## Configuration

Gedit is configured to use the SigmaOS theme system. Settings are stored in `~/.config/gedit/`.

## Usage

```bash
# Start Gedit
sigmaos-gedit

# Edit a file
sigmaos-gedit file.txt
```
