# SigmaOS MongoDB Compass

MongoDB Compass integration for SigmaOS - MongoDB GUI.

## Overview

SigmaOS MongoDB Compass provides a GUI for MongoDB. Integration with SigmaOS database and data analysis systems.

## Features

- **MongoDB GUI**: MongoDB graphical user interface
- **Query builder**: Visual query builder
- **Schema visualization**: Schema visualization
- **Aggregation pipeline**: Aggregation pipeline builder
- **Index management**: Index management
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-mongodb-compass
```

## Usage

```bash
# Start MongoDB Compass
sigmaos-mongodb-compass
```
