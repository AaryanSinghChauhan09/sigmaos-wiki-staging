# SigmaOS Creative Tools Complete

Complete collection of creative tools for SigmaOS - comprehensive creative software ecosystem.

## Overview

SigmaOS Creative Tools Complete provides a comprehensive collection of creative tools for various media types including image editing, vector graphics, 3D modeling, video editing, and more.

## Features

- **Image editing**: GIMP, Krita, Inkscape, Darktable
- **Vector graphics**: Inkscape, Draw.io, Excalidraw
- **3D modeling**: Blender, FreeCAD, OpenSCAD
- **Video editing**: Kdenlive, OBS Studio, Shotcut
- **Photo workflow**: Darktable, RawTherapee, digiKam
- **Audio editing**: Audacity, Ardour, LMMS
- **Diagramming**: Draw.io, Mermaid, PlantUML
- **Whiteboard**: Excalidraw, OpenBoard, tldraw

## Tools Included

### Image Editing
- **GIMP**: Advanced image editor
- **Krita**: Digital painting and illustration
- **Inkscape**: Vector graphics editor
- **Darktable**: Photo workflow and raw developer
- **RawTherapee**: Raw image processor
- **digiKam**: Photo management and editing

### Vector Graphics
- **Inkscape**: Vector graphics editor
- **Draw.io**: Diagramming tool
- **Excalidraw**: Virtual whiteboard
- **Mermaid**: Diagram generation
- **PlantUML**: UML diagram tool

### 3D Modeling
- **Blender**: 3D creation suite
- **FreeCAD**: Parametric 3D modeler
- **OpenSCAD**: Script-based 3D CAD
- **MeshLab**: 3D mesh processing

### Video Editing
- **Kdenlive**: Video editor
- **OBS Studio**: Video recording and streaming
- **Shotcut**: Video editor
- **OpenShot**: Video editor
- **Handbrake**: Video transcoder

### Audio Production
- **Audacity**: Audio editor
- **Ardour**: Digital audio workstation
- **LMMS**: Music production software
- **Rosegarden**: MIDI sequencer and notation editor
- **ZynAddSubFX**: Software synthesizer

### Diagramming & Whiteboarding
- **Draw.io**: Diagramming tool
- **Excalidraw**: Virtual whiteboard
- **OpenBoard**: Interactive whiteboard
- **tldraw**: Collaborative whiteboard
- **Miro**: Online whiteboard

## Installation

```bash
sudo pacman -S sigmaos-creative-tools-complete
```

## Configuration

Creative Tools Complete is configured to use the SigmaOS theme system. Tools are managed via package manager.

## Usage

```bash
# Install creative tools complete
sudo pacman -S sigmaos-creative-tools-complete

# List available tools
creative-tools-complete list

# Install a specific tool
creative-tools-complete install gimp
```
