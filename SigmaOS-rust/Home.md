# SigmaOS Rust

Rust integration for SigmaOS - Rust programming language runtime.

## Overview

SigmaOS Rust provides the Rust programming language runtime with SigmaOS-specific configurations and package management.

## Features

- **Rust runtime**: Latest Rust version
- **Cargo**: Rust package manager
- **SigmaOS bindings**: SigmaOS-specific Rust bindings
- **Development tools**: Development tools and libraries
- **Themes**: SigmaOS theme integration for Rust tools
- **Cross-compilation**: Support for cross-compilation

## Installation

```bash
sudo pacman -S sigmaos-rust
```

## Configuration

Rust is configured to use SigmaOS package management. Projects are created in `~/.local/share/rust/`.

## Usage

```bash
# Run Rust
rustc

# Run Cargo
cargo

# Create a new project
cargo new myproject

# Build a project
cargo build

# Run a project
cargo run
```
