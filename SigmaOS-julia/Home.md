# SigmaOS Julia

Julia integration for SigmaOS - high-level dynamic programming language.

## Overview

SigmaOS Julia provides a high-level dynamic programming language for technical computing. Integration with SigmaOS data science and scientific computing systems.

## Features

- **High-level**: High-level dynamic programming language
- **Performance**: Near C performance
- **Multiple dispatch**: Multiple dispatch paradigm
- **Scientific computing**: Scientific computing libraries
- **Data science**: Data science ecosystem
- **GPU support**: GPU acceleration
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-julia
```

## Usage

```julia
# Julia code
function hello(name)
    println("Hello, $name!")
end

hello("World")
```
