# SigmaOS R

R integration for SigmaOS - statistical programming language.

## Overview

SigmaOS R provides a statistical programming language for data analysis and visualization. Integration with SigmaOS data science and statistics systems.

## Features

- **Statistical computing**: Statistical computing and graphics
- **R language**: R programming language
- **Packages**: Extensive package ecosystem
- **Data analysis**: Data analysis and modeling
- **Visualization**: Data visualization with ggplot2
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-r
```

## Usage

```r
# R code
x <- c(1, 2, 3, 4, 5)
y <- x^2

# Print result
print(y)
```
