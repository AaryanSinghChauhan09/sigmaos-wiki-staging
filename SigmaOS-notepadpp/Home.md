# SigmaOS Notepad++

Notepad++ integration for SigmaOS - text and code editor.

## Overview

SigmaOS Notepad++ provides a text and code editor with advanced features. Integration with SigmaOS development tools.

## Features

- **Text editing**: Advanced text editing
- **Syntax highlighting**: Syntax highlighting for many languages
- **Plugins**: Plugin support
- **Search/replace**: Advanced search and replace
- **Macros**: Macro recording and playback
- **Themes**: SigmaOS theme integration
- **Multi-language**: Support for many programming languages
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-notepadpp
```

## Configuration

Notepad++ is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/notepadpp/`.

## Usage

```bash
# Start Notepad++
sigmaos-notepadpp

# Edit a file
notepadpp file.py
```
