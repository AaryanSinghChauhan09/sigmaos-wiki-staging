# SigmaOS Office Suites Complete

Complete collection of office suites for SigmaOS - comprehensive office software ecosystem.

## Overview

SigmaOS Office Suites Complete provides a comprehensive collection of office suites for productivity including word processing, spreadsheets, presentations, databases, and more.

## Features

- **Word processing**: LibreOffice Writer, OnlyOffice Document
- **Spreadsheets**: LibreOffice Calc, OnlyOffice Spreadsheet
- **Presentations**: LibreOffice Impress, OnlyOffice Presentation
- **Databases**: LibreOffice Base
- **Vector graphics**: LibreOffice Draw
- **Math equations**: LibreOffice Math
- **PDF tools**: PDF editors and converters
- **Office formats**: Support for various office formats

## Suites Included

### LibreOffice Suite
- **Writer**: Word processor
- **Calc**: Spreadsheet application
- **Impress**: Presentation software
- **Base**: Database management
- **Draw**: Vector graphics editor
- **Math**: Equation editor
- **Charts**: Chart editor
- **Extension**: Extension management

### OnlyOffice Suite
- **Document**: Word processor
- **Spreadsheet**: Spreadsheet application
- **Presentation**: Presentation software
- **PDF**: PDF editor
- **Forms**: Form builder

### Other Office Suites
- **OpenOffice**: Open-source office suite
- **SoftMaker Office**: Commercial office suite
- **WPS Office**: WPS Office suite
- **Calligra Suite**: KDE office suite
- **Scribus**: Desktop publishing

### Office Tools
- **PDF editors**: PDF editors and converters
- **Format converters**: Document format converters
- **OCR tools**: Optical character recognition
- **Signature tools**: Digital signature tools

## Installation

```bash
sudo pacman -S sigmaos-office-suites-complete
```

## Configuration

Office Suites Complete is configured to use the SigmaOS theme system. Suites are managed via package manager.

## Usage

```bash
# Install office suites complete
sudo pacman -S sigmaos-office-suites-complete

# List available suites
office-suites-complete list

# Install a specific suite
office-suites-complete install libreoffice
```
