# SigmaOS Thunderbird

Thunderbird integration for SigmaOS - open-source email client.

## Overview

SigmaOS Thunderbird provides a powerful, open-source email client with calendar integration. Built on Mozilla Thunderbird with SigmaOS theme integration.

## Features

- **Email**: Multiple account support (IMAP, POP3, SMTP)
- **Calendar**: Built-in calendar with CalDAV support
- **Address book**: Contact management with LDAP support
- **RSS/Atom**: Feed reader
- **Chat**: XMPP chat integration
- **Extensions**: Extensible add-on system
- **PGP**: OpenPGP encryption support
- **Search**: Advanced search with indexing

## Installation

```bash
sudo pacman -S sigmaos-thunderbird
```

## Configuration

Thunderbird is configured to use the SigmaOS theme system. Accounts are configured in the application settings.

## Usage

```bash
# Start Thunderbird
sigmaos-thunderbird
```
