# SigmaOS DBeaver

DBeaver integration for SigmaOS - universal database tool.

## Overview

SigmaOS DBeaver provides a universal database tool for connecting to various databases. Integration with SigmaOS database and data analysis systems.

## Features

- **Database tool**: Universal database tool
- **Multiple databases**: Support for multiple databases
- **SQL editor**: SQL editor with syntax highlighting
- **Data editor**: Data editor and viewer
- **ER diagrams**: Entity-relationship diagrams
- **Data transfer**: Data import/export
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-dbeaver
```

## Usage

```bash
# Start DBeaver
sigmaos-dbeaver
```
