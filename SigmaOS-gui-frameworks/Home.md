# SigmaOS GUI Frameworks

GUI frameworks collection for SigmaOS - collection of GUI frameworks for desktop applications.

## Overview

SigmaOS GUI Frameworks provides a collection of GUI frameworks for building desktop applications. Includes documentation and examples for each framework.

## Features

- **Framework collection**: Collection of GUI frameworks
- **Documentation**: Comprehensive documentation
- **Examples**: Example applications
- **Theme integration**: SigmaOS theme support
- **Performance**: Performance comparisons
- **Accessibility**: Accessibility support
- **Cross-platform**: Works across platforms
- **Community**: Community support and examples

## Frameworks Included

- **Qt**: Qt Quick and Qt Widgets
- **GTK**: GTK3 and GTK4 with libadwaita
- **Electron**: Electron.js
- **Tauri**: Tauri framework
- **Wails**: Wails framework
- **Flutter**: Flutter framework
- **React Native**: React Native Desktop
- **Python**: PyQt, PySide, tkinter
- **Rust**: Iced, Slint, egui
- **Others**: Avalonia, Uno Platform, and more

## Installation

```bash
sudo pacman -S sigmaos-gui-frameworks
```

## Configuration

GUI Frameworks is configured to use the SigmaOS theme system. Frameworks are managed via package manager.

## Usage

```bash
# Install GUI frameworks
sudo pacman -S sigmaos-gui-frameworks

# List available frameworks
gui-frameworks list

# View framework documentation
gui-frameworks docs qt
```
