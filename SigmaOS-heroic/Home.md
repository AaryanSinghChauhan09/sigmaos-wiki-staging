# SigmaOS Heroic

Heroic integration for SigmaOS - Epic Games launcher.

## Overview

SigmaOS Heroic provides an Epic Games launcher for Linux. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Epic Games**: Access Epic Games Store
- **Game library**: Manage game library
- **Cloud saves**: Cloud save synchronization
- **Proton**: Proton compatibility layer
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for performance
- **Community**: Community features
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-heroic
```

## Configuration

Heroic is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/heroic/`.

## Usage

```bash
# Start Heroic
sigmaos-heroic
```
