# SigmaOS GIMP

GIMP integration for SigmaOS - image editor.

## Overview

SigmaOS GIMP provides an image editor for photo editing and graphic design. Integration with SigmaOS creative and design systems.

## Features

- **Image editing**: Advanced image editing
- **Photo editing**: Photo editing tools
- **Graphic design**: Graphic design tools
- **Layers**: Layer support
- **Filters**: Filter effects
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-gimp
```

## Configuration

GIMP is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/gimp/`.

## Usage

```bash
# Start GIMP
sigmaos-gimp
```
