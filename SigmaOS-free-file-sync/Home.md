# SigmaOS Free File Sync

Free File Sync integration for SigmaOS - file synchronization tool.

## Overview

SigmaOS Free File Sync provides a file synchronization tool for keeping files in sync across devices. Integration with SigmaOS file management and sync systems.

## Features

- **File synchronization**: Synchronize files across devices
- **Real-time sync**: Real-time synchronization
- **Selective sync**: Choose which files to sync
- **Conflict resolution**: Conflict resolution
- **Bandwidth control**: Limit sync bandwidth
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-free-file-sync
```

## Configuration

Free File Sync is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/free-file-sync/`.

## Usage

```bash
# Start Free File Sync
sigmaos-free-file-sync

# Create sync pair
free-file-sync create-pair

# Sync files
free-file-sync sync
```
