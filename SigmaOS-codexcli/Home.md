# SigmaOS CodexCLI

CodexCLI integration for SigmaOS - AI coding assistant CLI.

## Overview

SigmaOS CodexCLI provides an AI coding assistant command-line interface. Integration with SigmaOS development tools and AI systems.

## Features

- **AI coding**: AI-powered code generation and completion
- **CLI interface**: Command-line interface
- **Code review**: Automated code review
- **Refactoring**: Code refactoring assistance
- **Testing**: Test generation
- **Documentation**: Documentation generation
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration

## Installation

```bash
sudo pacman -S sigmaos-codexcli
```

## Configuration

CodexCLI is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/codexcli/`.

## Usage

```bash
# Start CodexCLI
sigmaos-codexcli

# Generate code
codexcli generate "function to sort array"

# Review code
codexcli review file.py
```
