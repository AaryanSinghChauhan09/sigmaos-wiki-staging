# SigmaOS LibreOffice Calc

LibreOffice Calc integration for SigmaOS - spreadsheet software.

## Overview

SigmaOS LibreOffice Calc provides spreadsheet software for data analysis and calculations. Integration with SigmaOS office and data analysis systems.

## Features

- **Spreadsheets**: Create spreadsheets
- **Formulas**: Formula support
- **Charts**: Chart creation
- **Pivot tables**: Pivot table support
- **Data analysis**: Data analysis tools
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-calc
```

## Configuration

LibreOffice Calc is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Calc
sigmaos-libreoffice-calc
```
