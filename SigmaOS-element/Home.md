# SigmaOS Element

Element integration for SigmaOS - Matrix client.

## Overview

SigmaOS Element provides a Matrix client for secure messaging. Integration with SigmaOS communication and security systems.

## Features

- **Matrix protocol**: Matrix protocol support
- **End-to-end encryption**: End-to-end encryption
- **Group chat**: Group chat support
- **Voice/video**: Voice and video calls
- **File sharing**: File sharing
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-element
```

## Configuration

Element is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/element/`.

## Usage

```bash
# Start Element
sigmaos-element
```
