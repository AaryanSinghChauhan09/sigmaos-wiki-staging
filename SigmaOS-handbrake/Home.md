# SigmaOS Handbrake

Handbrake integration for SigmaOS - video transcoder.

## Overview

SigmaOS Handbrake provides a video transcoder for converting video formats. Integration with SigmaOS media and video processing systems.

## Features

- **Video transcoding**: Convert video formats
- **Batch processing**: Batch video processing
- **Presets**: Video encoding presets
- **Subtitles**: Subtitle support
- **Audio**: Audio encoding
- **Themes**: SigmaOS theme integration
- **CLI**: Command-line interface
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-handbrake
```

## Configuration

Handbrake is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/handbrake/`.

## Usage

```bash
# Start Handbrake
sigmaos-handbrake

# Transcode a video
HandBrakeCLI -i input.mp4 -o output.mkv
```
