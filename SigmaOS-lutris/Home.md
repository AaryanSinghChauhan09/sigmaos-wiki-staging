# SigmaOS Lutris

Lutris integration for SigmaOS - gaming platform.

## Overview

SigmaOS Lutris provides a gaming platform for managing games across multiple platforms. Integration with SigmaOS theme system and performance optimizations.

## Features

- **Game management**: Manage games from multiple sources
- **Wine/Proton**: Windows game compatibility
- **Dependencies**: Automatic dependency installation
- **Launchers**: Support for GOG, Steam, Epic, and more
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for gaming performance
- **Community**: Community scripts and ratings
- **Cloud sync**: Cloud save synchronization

## Installation

```bash
sudo pacman -S sigmaos-lutris
```

## Configuration

Lutris is configured to use the SigmaOS theme system. Games are stored in `~/Games/`.

## Usage

```bash
# Start Lutris
sigmaos-lutris

# Add a game
lutris add

# Run a game
lutris run game-name
```
