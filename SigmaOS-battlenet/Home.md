# SigmaOS Battle.net

Battle.net integration for SigmaOS - Blizzard game launcher.

## Overview

SigmaOS Battle.net provides a Blizzard game launcher for Linux. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Blizzard games**: Access Blizzard games
- **Game library**: Manage game library
- **Cloud saves**: Cloud save synchronization
- **Proton**: Proton compatibility layer
- **Themes**: SigmaOS theme integration
- **Performance**: Optimized for performance
- **Community**: Community features
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-battlenet
```

## Configuration

Battle.net is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/battlenet/`.

## Usage

```bash
# Start Battle.net
sigmaos-battlenet
```
