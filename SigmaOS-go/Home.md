# SigmaOS Go

Go integration for SigmaOS - Go programming language runtime.

## Overview

SigmaOS Go provides the Go programming language runtime with SigmaOS-specific configurations and package management.

## Features

- **Go runtime**: Latest Go version
- **Go modules**: Module support and package management
- **SigmaOS bindings**: SigmaOS-specific Go bindings
- **Development tools**: Development tools and libraries
- **Themes**: SigmaOS theme integration for Go tools
- **Cross-compilation**: Support for cross-compilation

## Installation

```bash
sudo pacman -S sigmaos-go
```

## Configuration

Go is configured to use SigmaOS package management. Projects are created in `~/.local/share/go/`.

## Usage

```bash
# Run Go
go

# Run a file
go run main.go

# Build a project
go build

# Install a package
go get package-name
```
