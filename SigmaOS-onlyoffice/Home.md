# SigmaOS OnlyOffice

OnlyOffice office suite configured for SigmaOS with enhanced integration and theming.

## Overview

SigmaOS OnlyOffice provides the OnlyOffice office suite with SigmaOS theming, enhanced performance, and desktop integration.

## Features

- Document Editor (word processing)
- Spreadsheet Editor
- Presentation Editor
- PDF Viewer and Editor
- Form Creator
- SigmaOS theme integration
- Collaborative editing

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install onlyoffice
```

## Components

The OnlyOffice suite includes:

- **Document Editor**: Word processing with SigmaOS templates
- **Spreadsheet Editor**: Spreadsheets with enhanced formulas
- **Presentation Editor**: Presentations with SigmaOS themes
- **PDF Editor**: PDF viewing and editing
- **Form Creator**: Form creation and management

## Configuration

OnlyOffice is pre-configured with:
- SigmaOS theme support
- Custom templates
- Collaborative features
- SigmaOS file picker integration
