# SigmaOS Zen

Zen web browser configured for SigmaOS with focus on simplicity and privacy.

## Overview

SigmaOS Zen provides Zen browser (Firefox fork) with a focus on simplicity, privacy, and modern design with SigmaOS integration.

## Features

- Zen browser (Firefox fork)
- Minimalist design
- Privacy-focused
- SigmaOS theme integration
- Modern UI
- Performance optimizations

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install zen
```

## Configuration

Zen is pre-configured with:
- SigmaOS theme support
- Minimalist interface
- Privacy settings
- Custom tab design
