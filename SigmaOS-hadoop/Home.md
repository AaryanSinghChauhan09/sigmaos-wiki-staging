# SigmaOS Hadoop

Hadoop integration for SigmaOS - distributed computing framework.

## Overview

SigmaOS Hadoop provides a distributed computing framework for big data processing. Integration with SigmaOS big data and distributed systems.

## Features

- **Distributed computing**: Distributed computing framework
- **HDFS**: Hadoop Distributed File System
- **MapReduce**: MapReduce programming model
- **YARN**: Yet Another Resource Negotiator
- **Hive**: SQL-like interface
- **Pig**: Data flow language
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-hadoop
```

## Usage

```bash
# Start Hadoop services
sudo systemctl start hadoop-namenode
sudo systemctl start hadoop-datanode

# Access HDFS
hdfs dfs -ls /
```
