# SigmaOS Cline

Cline integration for SigmaOS - AI coding assistant.

## Overview

SigmaOS Cline provides an AI coding assistant for VSCode. Integration with SigmaOS development tools and AI systems.

## Features

- **AI coding**: AI-powered code generation and completion
- **VSCode extension**: VSCode extension
- **Code review**: Automated code review
- **Refactoring**: Code refactoring assistance
- **Testing**: Test generation
- **Documentation**: Documentation generation
- **Themes**: SigmaOS theme integration
- **Security**: SigmaOS security integration

## Installation

```bash
sudo pacman -S sigmaos-cline
```

## Configuration

Cline is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/cline/`.

## Usage

```bash
# Install Cline extension
code --install-extension sigmaos.cline

# Use Cline
# Open VSCode and use Cline commands
```
