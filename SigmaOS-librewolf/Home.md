# SigmaOS LibreWolf

LibreWolf web browser configured for SigmaOS with maximum privacy and security.

## Overview

SigmaOS LibreWolf provides LibreWolf browser (Firefox fork) with enhanced privacy, telemetry removal, and SigmaOS integration.

## Features

- LibreWolf browser (Firefox privacy fork)
- Telemetry removed
- Enhanced privacy features
- SigmaOS theme integration
- uBlock Origin included
- No data collection

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install librewolf
```

## Configuration

LibreWolf is pre-configured with:
- SigmaOS theme support
- Maximum privacy settings
- Telemetry disabled
- Tracking protection enabled
- No data collection
