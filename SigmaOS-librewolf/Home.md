# SigmaOS-librewolf

LibreWolf hardened Firefox profile manager in Rust for SigmaOS.

## Overview

`SigmaOS-librewolf` manages hardened LibreWolf profiles, generates `librewolf.overrides.cfg`, and audits privacy settings.
