# SigmaOS LibreOffice Impress

LibreOffice Impress integration for SigmaOS - presentation software.

## Overview

SigmaOS LibreOffice Impress provides presentation software for creating slideshows. Integration with SigmaOS office and presentation systems.

## Features

- **Presentations**: Create presentations
- **Slides**: Slide management
- **Animations**: Slide animations and transitions
- **Themes**: Presentation themes
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-impress
```

## Configuration

LibreOffice Impress is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Impress
sigmaos-libreoffice-impress
```
