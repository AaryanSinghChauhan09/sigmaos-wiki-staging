# SigmaOS ReactOS

ReactOS integration for SigmaOS - open-source Windows-compatible OS.

## Overview

SigmaOS ReactOS provides an open-source Windows-compatible operating system for running Windows applications. Integration with SigmaOS virtualization and theme systems.

## Features

- **Windows compatibility**: Run Windows applications
- **Open source**: Free and open-source
- **Virtualization**: Run in VM or dual-boot
- **Themes**: SigmaOS theme integration
- **Drivers**: Hardware driver support
- **Applications**: Windows application compatibility
- **Security**: SigmaOS security integration
- **Performance**: Optimized for performance

## Installation

```bash
sudo pacman -S sigmaos-reactos
```

## Configuration

ReactOS is configured to use the SigmaOS theme system. VMs are stored in `~/.local/share/reactos/`.

## Usage

```bash
# Start ReactOS VM
sigmaos-reactos

# Create ReactOS VM
sigmaos-reactos-create
```
