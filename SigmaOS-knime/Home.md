# SigmaOS Knime

KNIME analytics platform integration for SigmaOS with enhanced theming and desktop integration.

## Overview

SigmaOS Knime provides KNIME Analytics Platform with SigmaOS theming, enhanced performance, and desktop integration for data science workflows.

## Features

- KNIME Analytics Platform
- Visual workflow designer
- Data mining and machine learning
- SigmaOS theme integration
- Desktop file picker integration
- Enhanced extensions

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install knime
```

## Components

KNIME includes:

- **KNIME Analytics Platform**: Visual workflow designer
- **KNIME Server**: Workflow execution server
- **Extensions**: Machine learning, data mining, text mining
- **Integrations**: Database, Hadoop, Spark connections

## Configuration

KNIME is pre-configured with:
- SigmaOS theme support
- Custom workspace styling
- Desktop file picker integration
- Enhanced memory settings
