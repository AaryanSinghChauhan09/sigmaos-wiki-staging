# SigmaOS VLC

VLC integration for SigmaOS - media player.

## Overview

SigmaOS VLC provides a media player for playing various media formats. Integration with SigmaOS media and entertainment systems.

## Features

- **Media playback**: Play various media formats
- **Video**: Video playback
- **Audio**: Audio playback
- **Streaming**: Stream media
- **Subtitles**: Subtitle support
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-vlc
```

## Configuration

VLC is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/vlc/`.

## Usage

```bash
# Start VLC
sigmaos-vlc

# Play a file
vlc file.mp4
```
