# SigmaOS LibreOffice Writer

LibreOffice Writer integration for SigmaOS - word processor.

## Overview

SigmaOS LibreOffice Writer provides word processing software for creating documents. Integration with SigmaOS office and writing systems.

## Features

- **Word processing**: Create documents
- **Formatting**: Text formatting
- **Styles**: Document styles
- **Tables**: Table support
- **Images**: Image support
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-writer
```

## Configuration

LibreOffice Writer is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Writer
sigmaos-libreoffice-writer
```
