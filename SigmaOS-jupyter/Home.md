# SigmaOS Jupyter

Jupyter Notebook integration for SigmaOS with enhanced theming and desktop integration.

## Overview

SigmaOS Jupyter provides Jupyter Notebook and JupyterLab with SigmaOS theming, enhanced performance, and desktop integration.

## Features

- Jupyter Notebook
- JupyterLab
- SigmaOS theme integration
- IPython kernel
- Multiple language kernels (Python, R, Julia)
- Desktop integration

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install jupyter
```

## Components

The Jupyter suite includes:

- **Jupyter Notebook**: Classic notebook interface
- **JupyterLab**: Next-generation web-based IDE
- **IPython**: Enhanced Python REPL
- **Kernels**: Python, R, Julia, and other language support

## Configuration

Jupyter is pre-configured with:
- SigmaOS theme support
- Custom notebook styling
- Desktop file picker integration
- Enhanced keyboard shortcuts
