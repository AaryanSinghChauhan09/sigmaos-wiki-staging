# SigmaOS IntelliJ IDEA

IntelliJ IDEA integration for SigmaOS - IDE for Java development.

## Overview

SigmaOS IntelliJ IDEA provides a comprehensive IDE for Java development with SigmaOS theme integration.

## Features

- **Java development**: Full Java development support
- **Smart completion**: Intelligent code completion
- **Refactoring**: Powerful refactoring tools
- **Debugging**: Advanced debugger
- **Version control**: Git, SVN, and Mercurial integration
- **Build tools**: Maven and Gradle support
- **Themes**: SigmaOS theme integration
- **Plugins**: Extensive plugin ecosystem

## Installation

```bash
sudo pacman -S sigmaos-idea
```

## Configuration

IntelliJ IDEA is configured to use the SigmaOS theme system. Settings are stored in `~/.config/JetBrains/IntelliJIdea/`.

## Usage

```bash
# Start IntelliJ IDEA
sigmaos-idea
```
