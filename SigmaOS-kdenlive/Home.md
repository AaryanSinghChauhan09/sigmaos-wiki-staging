# SigmaOS Kdenlive

Kdenlive integration for SigmaOS - video editor.

## Overview

SigmaOS Kdenlive provides a video editor for creating and editing videos. Integration with SigmaOS media and video editing systems.

## Features

- **Video editing**: Non-linear video editing
- **Timeline**: Timeline-based editing
- **Effects**: Video effects and transitions
- **Audio**: Audio editing and mixing
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-kdenlive
```

## Configuration

Kdenlive is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/kdenlive/`.

## Usage

```bash
# Start Kdenlive
sigmaos-kdenlive
```
