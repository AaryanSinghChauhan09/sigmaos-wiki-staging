# SigmaOS Statsmodels

Statsmodels integration for SigmaOS - statistical modeling library for Python.

## Overview

SigmaOS Statsmodels provides a statistical modeling library for Python. Integration with SigmaOS data science and statistics systems.

## Features

- **Statistical modeling**: Regression, time series, and more
- **Python**: Python API
- **Econometrics**: Econometric models
- **Time series**: Time series analysis
- **Hypothesis testing**: Statistical tests
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-statsmodels
```

## Usage

```python
import statsmodels.api as sm

# Create a regression model
X = sm.add_constant(X)
model = sm.OLS(y, X).fit()

# Print summary
print(model.summary())
```
