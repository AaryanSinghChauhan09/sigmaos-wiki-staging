# SigmaOS Mailspring

Mailspring integration for SigmaOS - modern email client.

## Overview

SigmaOS Mailspring provides a modern, fast email client with a clean interface. Built on Mailspring with SigmaOS theme integration.

## Features

- **Email**: Multiple account support (IMAP, Gmail, Office 365)
- **Unified inbox**: View all accounts in one inbox
- **Snooze**: Snooze emails for later
- **Send later**: Schedule emails to send later
- **Tracking**: Read receipts and link tracking
- **Templates**: Email templates
- **Search**: Fast full-text search
- **Themes**: SigmaOS theme integration

## Installation

```bash
sudo pacman -S sigmaos-mailspring
```

## Configuration

Mailspring is configured to use the SigmaOS theme system. Accounts are configured in the application settings.

## Usage

```bash
# Start Mailspring
sigmaos-mailspring
```
