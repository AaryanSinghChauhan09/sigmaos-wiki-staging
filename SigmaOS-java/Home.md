# SigmaOS Java

Java integration for SigmaOS - Java programming language runtime.

## Overview

SigmaOS Java provides the Java programming language runtime with SigmaOS-specific configurations and package management.

## Features

- **Java runtime**: Latest Java version (OpenJDK)
- **Maven**: Build tool and dependency management
- **Gradle**: Build tool and dependency management
- **SigmaOS bindings**: SigmaOS-specific Java bindings
- **Development tools**: Development tools and libraries
- **Themes**: SigmaOS theme integration for Java tools

## Installation

```bash
sudo pacman -S sigmaos-java
```

## Configuration

Java is configured to use SigmaOS package management. Projects are created in `~/.local/share/java/`.

## Usage

```bash
# Run Java
java

# Compile Java
javac

# Run Maven
mvn

# Run Gradle
gradle
```
