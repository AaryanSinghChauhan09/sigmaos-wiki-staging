# SigmaOS Osaka Jade Theme

Osaka Jade theme for SigmaOS - a green/jade color theme for the SigmaOS desktop environment.

## Overview

SigmaOS Osaka Jade Theme provides a green/jade color theme for the SigmaOS desktop environment, offering a calming aesthetic.

## Features

- **Green/jade colors**: Calming green color palette
- **Desktop integration**: Integration with SigmaOS desktop
- **Application theming**: Theme for supported applications
- **Light/dark variants**: Light and dark mode variants
- **Accent colors**: Matching accent colors
- **Consistent design**: Consistent design across components
