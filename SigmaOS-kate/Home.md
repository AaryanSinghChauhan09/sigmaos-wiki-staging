# SigmaOS Kate

Kate integration for SigmaOS - advanced text editor for KDE.

## Overview

SigmaOS Kate provides a feature-rich text editor with multi-document support and SigmaOS theme integration.

## Features

- **Multi-document**: Edit multiple files simultaneously
- **Syntax highlighting**: Support for many languages
- **Code folding**: Collapse code blocks
- **Session management**: Save and restore sessions
- **Themes**: SigmaOS theme integration
- **Plugins**: Extensible plugin system
- **Vi mode**: Vim-style editing mode
- **Split views**: Split window editing

## Installation

```bash
sudo pacman -S sigmaos-kate
```

## Configuration

Kate is configured to use the SigmaOS theme system. Settings are stored in `~/.config/katerc`.

## Usage

```bash
# Start Kate
sigmaos-kate

# Edit a file
sigmaos-kate file.txt
```
