# SigmaOS Excalidraw

Excalidraw integration for SigmaOS - virtual whiteboard for sketching.

## Overview

SigmaOS Excalidraw provides a virtual whiteboard for sketching and diagramming. Integration with SigmaOS productivity and design systems.

## Features

- **Whiteboard**: Virtual whiteboard
- **Sketching**: Hand-drawn style sketches
- **Collaboration**: Real-time collaboration
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Sharing**: Share drawings
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-excalidraw
```

## Configuration

Excalidraw is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/excalidraw/`.

## Usage

```bash
# Start Excalidraw
sigmaos-excalidraw
```
