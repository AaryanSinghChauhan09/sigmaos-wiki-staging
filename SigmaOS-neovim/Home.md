# SigmaOS Neovim

Neovim integration for SigmaOS - extensible, modal text editor.

## Overview

SigmaOS Neovim provides a modern, extensible modal text editor with Lua scripting and SigmaOS theme integration.

## Features

- **Modal editing**: Vim-style modal editing
- **Lua scripting**: Extensible with Lua
- **LSP support**: Language Server Protocol integration
- **Treesitter**: Advanced syntax highlighting
- **Telescope**: Fuzzy finder
- **Themes**: SigmaOS theme integration
- **Plugins**: Extensive plugin ecosystem
- **Remote editing**: Remote file editing

## Installation

```bash
sudo pacman -S sigmaos-neovim
```

## Configuration

Neovim is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/nvim/`.

## Usage

```bash
# Start Neovim
sigmaos-neovim

# Edit a file
sigmaos-neovim file.txt
```
