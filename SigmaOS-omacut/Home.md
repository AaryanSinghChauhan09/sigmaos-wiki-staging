# SigmaOS Omacut

Clipboard and cut/copy/paste utilities for SigmaOS - enhanced clipboard management and tools.

## Overview

SigmaOS Omacut provides enhanced clipboard management and cut/copy/paste utilities for SigmaOS.

## Features

- **Clipboard history**: Track clipboard history
- **Advanced paste**: Paste with formatting options
- **Clipboard sync**: Sync clipboard across devices
- **Text processing**: Text processing on clipboard content
- **Hotkeys**: Customizable clipboard hotkeys
- **Search**: Search clipboard history
- **Privacy**: Password protection for sensitive clips
