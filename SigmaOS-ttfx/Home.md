# SigmaOS TTFX

Text transformation framework for SigmaOS - text processing and transformation utilities.

## Overview

SigmaOS TTFX provides a text transformation framework for processing and transforming text in SigmaOS.

## Features

- **Text transformation**: Transform text between formats
- **Filters**: Text filtering and processing
- **Pipelines**: Text processing pipelines
- **Regex support**: Regular expression processing
- **Encoding**: Text encoding conversion
- **Templates**: Text template processing
- **Integration**: Integration with SigmaOS tools
