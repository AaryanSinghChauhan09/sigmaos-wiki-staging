# SigmaOS Superset

Superset integration for SigmaOS - Apache Superset BI platform.

## Overview

SigmaOS Superset provides Apache Superset BI platform for data exploration and visualization. Integration with SigmaOS data analysis and visualization systems.

## Features

- **Business intelligence**: Business intelligence platform
- **Data exploration**: SQL Lab for data exploration
- **Visualization**: Rich chart types and dashboards
- **Database support**: Connect to multiple databases
- **Security**: Row-level security and access control
- **API**: REST API for programmatic access
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-superset
```

## Usage

```bash
# Start Superset
sudo systemctl start sigmaos-superset

# Access web interface
http://localhost:8088
```
