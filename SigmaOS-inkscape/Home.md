# SigmaOS Inkscape

Inkscape integration for SigmaOS - vector graphics editor.

## Overview

SigmaOS Inkscape provides a vector graphics editor for creating SVG graphics. Integration with SigmaOS creative and design systems.

## Features

- **Vector graphics**: Create vector graphics
- **SVG support**: SVG format support
- **Drawing tools**: Various drawing tools
- **Text tools**: Text editing tools
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Plugins**: Plugin support
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-inkscape
```

## Configuration

Inkscape is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/inkscape/`.

## Usage

```bash
# Start Inkscape
sigmaos-inkscape
```
