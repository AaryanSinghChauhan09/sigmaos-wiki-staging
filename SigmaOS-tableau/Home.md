# SigmaOS Tableau

Tableau integration for SigmaOS - business intelligence and data visualization platform.

## Overview

SigmaOS Tableau provides a business intelligence and data visualization platform. Integration with SigmaOS data analysis and visualization systems.

## Features

- **Business intelligence**: Business intelligence platform
- **Data visualization**: Interactive data visualization
- **Dashboards**: Dashboard creation and sharing
- **Data sources**: Connect to multiple data sources
- **Themes**: SigmaOS theme integration
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem
- **Performance**: Optimized for performance

## Installation

```bash
sudo pacman -S sigmaos-tableau
```

## Usage

```bash
# Start Tableau
sigmaos-tableau
```
