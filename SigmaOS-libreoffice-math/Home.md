# SigmaOS LibreOffice Math

LibreOffice Math integration for SigmaOS - equation editor.

## Overview

SigmaOS LibreOffice Math provides an equation editor for creating mathematical formulas. Integration with SigmaOS office and math systems.

## Features

- **Equation editor**: Create mathematical equations
- **Formula support**: Support for various formulas
- **Symbols**: Mathematical symbols
- **Export**: Export to various formats
- **Themes**: SigmaOS theme integration
- **Integration**: Integrates with other LibreOffice apps
- **Documentation**: Comprehensive documentation
- **Community**: Large community and ecosystem

## Installation

```bash
sudo pacman -S sigmaos-libreoffice-math
```

## Configuration

LibreOffice Math is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/libreoffice/`.

## Usage

```bash
# Start LibreOffice Math
sigmaos-libreoffice-math
```
