# SigmaOS Waterfox

Waterfox web browser configured for SigmaOS with privacy and performance focus.

## Overview

SigmaOS Waterfox provides Waterfox browser (Firefox fork) with enhanced privacy, customization options, and SigmaOS integration.

## Features

- Waterfox browser (Firefox fork)
- Privacy-focused
- Customization options
- SigmaOS theme integration
- Legacy extension support
- Performance optimizations

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install waterfox
```

## Configuration

Waterfox is pre-configured with:
- SigmaOS theme support
- Privacy settings
- Custom tab bar
- Classic extensions support
