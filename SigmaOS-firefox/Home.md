# SigmaOS Firefox

Firefox web browser configured for SigmaOS with enhanced privacy and integration.

## Overview

SigmaOS Firefox provides Firefox browser with SigmaOS theming, privacy enhancements, and desktop integration.

## Features

- Firefox browser
- SigmaOS theme integration
- Privacy enhancements
- Container tabs
- Enhanced tracking protection
- SigmaOS integration

## Installation

Install via SigmaOS package manager:

```bash
sigmaos install firefox
```

## Configuration

Firefox is pre-configured with:
- SigmaOS theme support
- Enhanced privacy settings
- Tracking protection enabled
- Container tabs for isolation
