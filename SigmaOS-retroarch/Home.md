# SigmaOS RetroArch

RetroArch integration for SigmaOS - retro gaming emulator.

## Overview

SigmaOS RetroArch provides a retro gaming emulator for playing classic games. Integration with SigmaOS gaming and entertainment systems.

## Features

- **Retro gaming**: Play retro games
- **Multiple systems**: Support for multiple retro systems
- **Emulation cores**: Various emulation cores
- **Netplay**: Netplay support
- **Shaders**: Shader support
- **Themes**: SigmaOS theme integration
- **Customization**: Highly customizable
- **Documentation**: Comprehensive documentation

## Installation

```bash
sudo pacman -S sigmaos-retroarch
```

## Configuration

RetroArch is configured to use the SigmaOS theme system. Configuration is stored in `~/.config/retroarch/`.

## Usage

```bash
# Start RetroArch
sigmaos-retroarch
```
